# 🐚 The Coastal Spoon — Restaurant Website

A fully responsive, interactive restaurant website built as part of the
DecodeLabs Frontend Development Internship (Batch 2026).

---

## 📌 Description

The Coastal Spoon is a multi-page static restaurant website for a fictional
coastal dining restaurant based in Blue Area, Islamabad. The project was built
across three milestones, each focusing on a core frontend skill:

- **Project 3** — JavaScript DOM manipulation and interactive web elements

---

## ✨ Features

- Responsive navigation with hamburger menu (HTML Popover API)
- Dark mode toggle with localStorage persistence
- Menu category filter (Seafood, Veggie, Pasta, NonVeg)
- Add to Cart system with live total and item removal
- FAQ accordion with smooth open/close animation
- Mobile-first layout using CSS Grid and Flexbox
- Fluid typography with clamp()
- Accessible — WCAG touch targets, aria labels, semantic HTML

---

## 🛠️ Technologies Used

- HTML5 (Semantic)
- CSS3 (Grid, Flexbox, Custom Properties, Media Queries)
- Vanilla JavaScript (DOM Manipulation, localStorage, Event Listeners)

---

## 🚀 How to Run

No installation or commands needed — this is a pure HTML/CSS/JS project.

1. Download or clone the repository
2. Open `index.html` in any modern browser
3. That's it

Or view the live demo here: [Live Preview] https://the-coastal-spoon3.netlify.app
